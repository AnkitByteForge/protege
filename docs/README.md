# PROTÉGÉ Engineering Documents

## Source hierarchy

1. `PROTEGE_ARCHITECTURE.md`
   - Original complete product + architecture specification.

2. `PROTEGE_ENGINEERING_ADDENDUM.md`
   - Engineering corrections and superseding decisions.
   - Where it conflicts with v1.0 engineering decisions, this document wins.

3. `PROTEGE_IMPLEMENTATION_ROADMAP.md`
   - Reconciled master implementation roadmap.
   - This is the execution plan derived from the two documents above.

When implementing:
- Preserve product decisions from the architecture.
- Apply engineering corrections from the addendum.
- Follow the roadmap for sequencing.
- Do not silently reintroduce superseded decisions.
