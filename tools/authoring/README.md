# tools/authoring — offline authoring

Fable 5.1 (via the `anthropic` SDK) is used **here only, offline**, from P3
onwards: drafting misconception-library records, golden sets, and red-team
cases, with human ratification before anything enters the repo. It is never a
runtime dependency of the session service (addendum §1.3, §9.4–9.5).

Intentionally dependency-free at P0.
